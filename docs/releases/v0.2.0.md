# smob v0.2.0

v0.2.0 adds S3-compatible storage, Docker container metrics, disk retention, and
range-wide summaries on top of the v0.1 system, process, disk, and query core.

## Highlights

- **S3-compatible storage.** Write to AWS S3, MinIO, or another S3-compatible
  endpoint using the standard AWS credential chain. Transient failures are
  retried with exponential backoff and jitter; a chunk that still cannot be
  uploaded is written to a local spool and replayed in the background. Queries
  merge readable spool entries with the bucket, and the same chunk keys and
  sample format are used for disk and S3.
- **Docker container metrics.** Collect per-container CPU, memory, and
  per-interface network usage through the Docker Engine API, with `container`,
  `image`, and `scope=container` labels. One-shot polling is the default; stats
  streams are opt-in. The source is disabled by default and fails startup when
  it is enabled and the socket is unreachable.
- **Bounded disk usage.** A startup and hourly retention sweep deletes closed
  disk chunks by age or total size. The active chunk, temporary files, and the
  S3 spool are never touched.
- **Summaries and aggregation.** `smob stats` reports count, min, max, and mean
  per metric over a range. `query --agg avg|min|max|sum --group-by` aggregates
  samples by metric and label, weighting rate averages by `interval_ms`.
- **Operator documentation.** A quickstart, full configuration reference,
  S3/IAM guide, disk-to-S3 migration guide, Docker deployment guide, hardened
  systemd unit, and Compose example ship with this release.
- **CLI polish.** The root `--version` flag prints the same banner as
  `smob version`, and help and version output have integration coverage.

## Upgrade notes

- Existing disk chunks remain readable; the chunk format and key layout are
  unchanged from v0.1.
- New configuration fields are optional. The Docker source remains disabled
  unless `sources.docker.enabled: true` is set.

## Known limitations

- `smob tail` is still a stub. Live tail, a chunk index, compaction, and
  multi-host aggregation or remote query are planned for v0.3.
- Docker collection requires access to the Docker socket; see the container
  deployment guide for the permission and namespace requirements.
